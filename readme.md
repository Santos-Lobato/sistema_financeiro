Sistema de Controle Financeiro Pessoal
Sistema web desenvolvido em Python com Flask e SQLite.

Funcionalidades
* Organização financeira entre receitas e despesas
* Captação e armazenamento de transações bancárias 
* Relatórios em tempo real: balanço geral, categorias e período
* CRUD completo de categorias e transações


Tecnologias
* Python 3
* Flask
* SQLite3
* Python-dotenv


Como executar
1. Instale as dependências: pip install flask python-dotenv
2. Crie um arquivo .env com: SECRET_KEY=sua_chave_aqui
3. Execute: python app.py
4. Acesse: http://127.0.0.1:5000/categorias
